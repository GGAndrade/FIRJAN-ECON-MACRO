# 📊 Dashboard Econômico - Firjan

Aplicação interativa de visualização e análise de dados macroeconômicos e indicadores da indústria da **Gerência de Estudos Econômicos (GEE)** da **Firjan**, desenvolvida com **Streamlit**.

---

## 🚀 Funcionalidades

- **📈 Dados MACRO (Início):** Panorama macroeconômico com indicadores de produção, emprego, inflação e investimentos industriais.
- **📉 Indústria no Mundo:** Análise do desempenho comparativo da indústria global com dados da UNIDO e gráficos interativos Altair.
- **🌐 Tradutor GPT:** Assistente de tradução e sumarização de textos e estudos econômicos internacionais.
- **📊 Coeficientes de Abertura Comercial (CAC):** Monitoramento dos fluxos e coeficientes de comércio exterior da indústria brasileira.
- **🏛️ Identidade Visual Firjan:** Layout institucional completo, paleta de cores corporativa, logos oficiais das entidades (Firjan, SENAI, SESI, IEL, CIRJ) e rodapé integrado.

## 💻 Como Executar Localmente

### Pré-requisitos
- Python 3.10+ instalado

### 1. Clonar o repositório
```bash
git clone https://github.com/GGAndrade/CNI-ECON-GERAL.git
cd CNI-ECON-GERAL
```

### 2. Criar e ativar o ambiente virtual
```bash
python -m venv .venv
# No Windows:
.venv\Scripts\activate
# No Linux/Mac:
source .venv/bin/activate
```

### 3. Instalar dependências
```bash
pip install -r requirements.txt
```

### 4. Executar a aplicação
```bash
streamlit run INICIO.py
```
Acesse no seu navegador: `http://localhost:8501`
